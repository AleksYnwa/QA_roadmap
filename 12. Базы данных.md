**База данных (БД)** – это организованное хранилище цифровой информации. База данных позволяет не только хранить, но и изменять, извлекать и удалять информацию. БД содержит все данные, касающиеся различных компонентов приложения.
Существует множество видов баз данных, но основные это реляционные и нереляционные.
#### Из чего состоят таблицы в БД

**Реляционная БД** имеет **табличную** организацию хранения данных с предопределенными связями между ними. В **столбце** хранится определенный тип данных, в каждой **ячейке** – значение атрибута. **Строка** представляет собой набор связанных значений, относящихся к одной сущности.

**Ключ СУБД** – это атрибут или набор атрибутов, который помогает идентифицировать строку в таблице.

**Первичный ключ** (Primary Key) – это специальное поле (или комбинация полей) в таблице базы данных, которое **уникально идентифицирует каждую запись**. 
Он служит основой для построения связей между таблицами и позволяет базе данных быстро находить, обновлять или удалять конкретную запись. 

> [!tip]+ Важно
> Главное свойство в том, что значение первичного ключа всегда уникально и никогда не может быть `NULL`, иначе система просто не сможет корректно различать строки и работать со связями.

**Ключ внешний** (Foreign Key) – это поле (или набор полей) в таблице, которое ссылается на первичный ключ (PK) другой таблицы. Он обеспечивает связь между таблицами и поддерживает целостность данных.
#### Что такое SQL?

**SQL** – язык структурированных запросов, позволяющий хранить, изменять и извлекать данные из реляционных БД.
**СУБД** – системы управления базами данных.
#### SQL-запросы

Это набор команд для работы с реляционными базами данных. 

С помощью SQL-запросов можно:
- Создать базу данных. Описать её структуру и настроить правила расположения информации.
- Проводить операции с данными в БД. Добавить, обновить, извлечь или удалить данные.
- Управлять доступом к объектам базы данных. Предоставить или отозвать права доступа.
- Управлять транзакциями. Обеспечить целостность и согласованность данных при выполнении нескольких операций, позволяя откатить изменения.
#### Базовые операторы SQL

- INSERT — вставка новых данных
    INSERT INTO table_name (column1, column2) VALUES (value1, value2);
- UPDATE — обновление данных
    UPDATE table_name SET column1 = value1 WHERE condition;
- DELETE — удаление данных
    DELETE FROM table_name WHERE condition;
- ORDER_BY — сортировка данных
    SELECT * FROM table_name ORDER BY column1 ASC|DESC;
- DISTINCT — уникальные значения
    SELECT DISTINCT column1 FROM table_name;
- COUNT — подсчет строк
    SELECT COUNT(`*`) FROM table_name;
- SUM — сумма значений
    SELECT SUM(column1) FROM table_name;
- LIMIT — ограничение выборки
    SELECT * FROM table_name LIMIT 10;
- JOIN — соединение таблиц
    SELECT * FROM table1 JOIN table2 ON [table1.id]() = [table2.id]();
